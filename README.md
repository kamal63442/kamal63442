# Kawal

**Independent developer and researcher exploring AI agents, evaluation, safe local improvement, and reliable frontier-model systems.**

I build and experiment with AI-agent workflows, coding agents, model orchestration, evaluation infrastructure, and mechanisms for making persistent agent improvements more observable, testable, reversible, and human-controlled.

My current research focus is **Local Evolution Core**: an experimental framework for studying whether AI systems can improve persistent parts of their local operating environment—such as prompts, tools, strategies, memory, workflows, and evaluation procedures—while keeping the underlying frontier model unchanged.

> I treat recursive / iterative improvement as a research question, not a demonstrated result. Public claims here distinguish ongoing experiments from validated findings.

## Current research

### [Local Evolution Core](https://github.com/kamal63442/local-evolution-core)

An experimental research framework for studying **bounded, observable, reversible local improvement** in frontier-model agent systems.

Current themes include:

- candidate generation and quarantine before promotion
- held-out and sealed evaluation
- rollback and provenance tracking
- cross-model evaluation and evaluator disagreement
- regression detection and transfer testing
- bounded resource use and audit-friendly telemetry
- explicit human-controlled promotion

The public repository documents the research design, safety model, evaluation methodology, architecture, and roadmap. Results will only be added when supported by completed experiments.
